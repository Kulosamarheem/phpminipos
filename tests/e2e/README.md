# End-to-end test (Playwright)

ทดสอบ 2 ฟีเจอร์ผ่านเบราว์เซอร์จริงพร้อมบันทึกวิดีโอ:

- **แก้ไขสินค้าในหน้า `products.php`** — แก้ในแถวตาราง, บันทึกลงฐานข้อมูล, เคสบาร์โค้ดซ้ำ, เคสยกเลิก, เคส validate
- **ยอดสุทธิรวมภาษีในหน้า `pos.php`** — ยอดรวม / ส่วนลด / VAT / สุทธิ / เงินทอน และการันตีว่าตรงกับยอดที่ `checkout.php` บันทึกจริง

ส่วนนี้เป็น Node ล้วน แยกออกจากตัวแอป PHP ที่ไม่มี dependency ใด ๆ

## ติดตั้ง (ครั้งเดียว)

```bash
cd "tests/e2e" && npm install && npx playwright install chromium
```

## รัน

```bash
cd "tests/e2e" && npm test
```

- เปิด PHP dev server ที่ `127.0.0.1:8123` ให้เอง (คนละพอร์ตกับ `start.bat` ที่ใช้ 8000) แล้วปิดเมื่อจบ
- สร้างผู้ใช้ทดสอบ `pos_e2e` ก่อนเริ่ม และปิดการใช้งานเมื่อจบ — **ไม่แตะบัญชีจริงของร้าน**
- สินค้าที่สร้างระหว่างเทสต์ใช้บาร์โค้ดขึ้นต้นด้วย `E2E-` และถูกปิดการขายเมื่อจบ
  (ปิดการขาย ไม่ใช่ลบจริง เพราะ `order_items` / `stock_movements` มี FK แบบ RESTRICT)

## วิดีโอสาธิต

```bash
cd "tests/e2e" && npm run demo
```

เดินทุกขั้นแบบช้าลงให้ดูรู้เรื่อง (`slowMo: 350`) ตั้งแต่เพิ่มสินค้า → แก้ไข → ขาย → เห็นยอดสุทธิ → ปิดบิล
วิดีโอออกที่ `test-results/demo-.../video.webm`

วิดีโอของเทสต์ปกติก็ถูกบันทึกทุกครั้งเช่นกัน (`video: 'on'`) อยู่ที่ `test-results/<ชื่อเทสต์>/video.webm`
ดูรายงานพร้อมวิดีโอฝังในหน้าเว็บ:

```bash
cd "tests/e2e" && npm run report
```

## ตั้งค่าผ่าน environment variable

| ตัวแปร | ค่าตั้งต้น | ใช้ทำอะไร |
|---|---|---|
| `POS_PHP_BIN` | `C:\xampp\php\php.exe` | พาธของ php (เครื่องนี้ไม่มี php ใน PATH) |
| `POS_TEST_PORT` | `8123` | พอร์ตของ dev server ที่เทสต์เปิดเอง |
| `POS_TEST_URL` | `http://127.0.0.1:8123` | ใช้เมื่อต้องการชี้ไปเซิร์ฟเวอร์อื่น |
| `POS_TEST_USER` | `pos_e2e` | ชื่อผู้ใช้ทดสอบ |
| `POS_TEST_PASS` | `pos_e2e_pass` | รหัสผ่านผู้ใช้ทดสอบ |

> ใช้ `127.0.0.1` ไม่ใช่ `localhost` — `php -S localhost:PORT` บน Windows จะผูกกับ `::1` อย่างเดียว

## เทสต์อื่นในโปรเจกต์ (PHP CLI ไม่ต้องใช้ Node)

```bash
/c/xampp/php/php.exe tests/vat_breakdown.php
```

ตรวจสูตร VAT ของ `money_order_totals()` ด้วยตัวเลขที่คำนวณด้วยมือ และเทียบกับสูตรเดิมของ `checkout.php` ทุกยอดตั้งแต่ 0.00–20.00 บาท
